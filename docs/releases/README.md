Each release has its own `<tag>/` directory. Place `<tag>.en-US.md`, `<tag>.zh-CN.md` and all screenshots directly in that directory. Do not create an image subdirectory. Keep previous releases instead of overwriting them.

Use the English text for the GitHub Release body, with a link to the Chinese document. When copying the notes into the Release page, use full GitHub URLs under that release tag for language links and screenshots. Relative links in the repository documents work within the version directory.

Publishing the Markdown files to the repository does not automatically update the GitHub Release description; paste the chosen text into the release description separately.
