# Astral 下一版开发清单

五步传动系统重做已完成。本轮从现有控制器和整车标定接着做。

## 本版主线

- [ ] **1. 自制车内仪表屏。** 电控会话负责。三种仪表支架目前共用 BeamNG 的赛车仪表页，下一步换成 Astral 自己的 HTML 行车页。第一版先显示实际挡位、转速、发动机 MAP 和发车状态。比如选了 LC2 和已经激活 LC2，车手要能一眼分清。
- [ ] **2. 调校发动机和传动电控。** 电控会话主调，本会话带入各车赛段实测。先看 Road 和 Stage 的升降挡、限转与换挡时机，再用同车同挡的收油回踩比较各级 ALS 和增压恢复。发车单独看建压、限转和起步退出。用新屏把驾驶员选的档位和控制器实际反应对起来。
- [ ] **3. 增加各车型的下压力和阻力，优先修尾翼侧面受风。** 悬挂与传动会话主责。沿用 180 km/h 风洞数据，先在相同车高、相同风速下测正对来流，再测左右相同的偏航角。单独改变端板参与受风的三角面，对比侧向力和车尾转动趋势。修正后再分车型定下压力和阻力增量，并回到赛段验证高速侧滑。
- [ ] **4. 给 WRC17 主动中差加驾驶员输入。** 两个拇指滚轮分别选择油门 map 和刹车 map。悬挂与传动会话负责研究每档改变什么，再在中差控制器提供切换和读取当前档位的接口。电控会话接入游戏按键绑定和仪表显示。档数、曲线和默认值留到研究时定。
- [ ] **5. 检查悬挂 JBeam 的结构、阻尼和刚度。** 悬挂与传动会话主责。从承载、支柱导向和行程限位用到的节点和梁查起。有明确问题再调参数，用同一预设、同一路段比较前后表现。需要看减振器动作时沿用现有轴速 CSV 记录器。
- [ ] **6. 刹车热力学与稳定性调整。**

## 有余力再做

- [ ] **7. Rally1 2022 混动。** 悬挂与传动会话负责电机接入传动系统的位置和整车参数，电控会话负责能量回收、部署和仪表状态。排在上述六项之后。

## 从哪里开始

「Astral 电控开发」先做三个支架共用的行车页，随后用它调校现有电控。「Astral 悬挂与传动系统」可以同时做尾翼端板的侧向来流对照。两边在主动中差接入滚轮时汇合，仪表直接读中差控制器当前生效的档位。
